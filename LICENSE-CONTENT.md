# Materials imprimibles de Sentit

Els textos i la composició originals de les fitxes i dels solucionaris de **Sentit**, un projecte d’**ortogra.fi** creat per **Aarón Fortuño i contribuïdors**, es publiquen sota **[Creative Commons Reconeixement 4.0 Internacional (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)**.

Referència del projecte: **https://sentit.ortogra.fi/**. El codi de cada comprensió identifica el material.

Les fonts tradicionals, les imatges, les gravacions, les músiques i els altres recursos amb atribució pròpia conserven la llicència indicada als [crèdits](CREDITS.md), als [crèdits sonors](docs/fonts-sonores.md) i als registres de cada material. La indicació del peu es refereix a les aportacions originals del material imprès.

El codi de l’aplicació conserva la seva [llicència MIT](LICENSE).
