# Prioritats per equilibrar el catàleg

Actualitzat el **25/11/2026**. L’adaptació ABCD del fons anterior està resolta i el docent ha reprès l’autoria. La primera tanda prevista ja té els **16 guions S112–S127**, amb doble format i revisió independent, pendents del seu vistiplau. [Pla, codis i lots compatibles](pla-equilibri-2026-11-25.md) · [Recompte actual dels cinc filtres](equilibri-cataleg.md).

La selecció reforça les mancances detectades en el fons inicial de 119 entrades: vuit notícies breus (quatre de 3r i quatre de 4t), quatre explicacions (dues de cada curs), dues instruccions de 3r–4t i dues entrevistes de 5è. S’afegeixen set peces de 3r, set de 4t i dues de 5è. Els diàlegs i les narracions conserven el fons existent mentre creixen les altres tipologies. Les variants continuen comptant com a entrades pròpies.

**Prioritat immediata:** validar aquests guions per blocs de repartiment. Mar, Mireia/Laia i Biel/Elies tenen candidats de sis a vuit minuts que poden acollir esmenes pendents. Les previsions es recalculen amb els textos acceptats, sense farciment ni síntesi prematura. Confirmar curs, dificultat i durada després de les veus i el muntatge, mantenint les dues audicions separades.

**Pas següent:** confirmar l’oferta curta real amb les durades mesurades; continuar ampliant explicacions i instruccions accessibles segons l’ús docent. Cap intenció d’igualar artificialment totes les quotes. Ferran i altres veus amb esmenes curtes necessitaran complements propis que aportin noves situacions útils.

**Cicle inicial:** es conserven per a una fase posterior dos pilots de Situacions quotidianes d’uns 35–55 segons, amb tres o quatre preguntes i poc text escrit. Encara cal adaptar i validar cursos, fitxa i calibratge per a 1r–2n. L’ampliació d’ESO i d’altres idiomes tindrà un pla propi.

**Nova línia cultural proposada pel docent (25/11):** [Faules del món, Llegendes d’aquí i d’arreu i Mites de l’antiguitat](univers-editorial.md). Els primers [pilots S128–S130](pilots-tradicio.md) ja tenen font i adaptació identificades, preguntes obertes/ABCD i revisió independent; esperen validació docent. Les faules poden reforçar el cicle inicial i mitjà; llegendes i mites aporten narracions graduades per a mitjà, superior i ESO. Narrador amb timbre flexible per completar lots compatibles, sense desplaçar la validació de S112–S127 ni sintetitzar material encara no aprovat.
