# Una mateixa història, diferents suports i dificultats

Línia futura proposada pel docent el **22/11/2026**, orientada al DUA. Es valorarà després de consolidar el catàleg actual i la producció de veus. Encara no crea nivells, famílies ni controls nous a la interfície.

## Objectiu compartit

Treballar una mateixa situació, personatges i idees centrals amb versions que permetin ajustar la dificultat i els suports. Això pot facilitar que una classe comparteixi la història mentre el docent tria què necessita cada alumne.

El punt de partida pot ser una peça com S046: mantenir el record de l’avi Ferran i preparar altres maneres de seguir-lo, conservant el seu interès, l’humor i la resolució. Una versió dialogada afegeix un altre referent auditiu; cal valorar-ne l’efecte real abans d’assignar-li una dificultat inferior.

## Dues decisions per separar

- **Suports d’accés i resposta:** context previ, document visual necessari o opcional, pauses, nombre d’escoltes, ritme, format imprès, espai de resposta o una resposta que es pugui marcar en lloc d’escriure extensament.
- **Dificultat del contingut:** densitat d’informació, longitud dels torns, claredat dels referents, vocabulari, quantitat de dades que s’han de relacionar i inferències que demanen les preguntes.

Es poden combinar. Ajustar només la tipografia o la velocitat no modifica per si mateix la complexitat de les relacions entre idees; reformular un guió també requereix revisar preguntes, respostes i ancoratges.

## Com preparar les versions

1. Identificar les idees i els fets que es conservaran a tota la família, i què es vol treballar amb cadascuna.
2. Per a una proposta amb més suport, clarificar referents i distribuir millor la informació, mantenint una conversa natural. Evitar els aclariments anticipats d’obvietats que ja hem descartat i les pistes que regalen respostes.
3. Per a una proposta amb més repte, augmentar relacions o inferències justificades pel relat. Aina, Laia i Biel continuen parlant com a joves; la dificultat no s’obté fent-los parlar com especialistes o allargant artificialment l’àudio.
4. Revisió independent i validació docent de cada versió amb el seu guió, preguntes i muntatge. Conservar les versions prèvies i separar l’aprovació del guió de l’audició del resultat.
5. Produir per lots compatibles de sis a vuit minuts i repartiment constant, aprofitant la quota sense alterar les històries per omplir-la.

## Organització futura

Relacionar les versions amb una família comuna i donar a cadascuna un codi estable, guió, preguntes, aprovacions i àudio propis. Conservar veus, identitats visuals i univers; compartir música o il·lustracions quan siguin adequades a la mateixa història.

El docent ha de poder veure què canvia entre versions i triar-les sense presentar-les a l’alumnat com una classificació de capacitats. El vocabulari i la presentació d’aquesta tria es decidiran amb un primer pilot. Les variants dialogades actuals es mantenen com a peces independents mentre aquesta organització no estigui definida.
