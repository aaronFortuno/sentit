## Preparació de lots

Tots tenen una sola veu narradora, anònima, sense crear recurrents nous. El timbre és flexible fins a congelar la petició; després es manté estable dins la peça. Cada relat ja identifica el tall complet de veu i la presentació. El paquet final les pot agrupar en una petició i separar-les localment després de comprovar la cobertura i els silencis.

Les previsions no autoritzen cap petició. Els grups petits esperen o es combinen amb altres narracions compatibles ja validades; no s’allarguen les faules per arribar als sis minuts. Les parts destinades a una base musical es munten després de l’audició de veus. Cap resposta requereix veure una imatge ni reconèixer un efecte.

## Criteris de tradició i revisió

Adaptacions catalanes pròpies a partir de relats antics i fonts identificades a cada escaleta. Les llegendes es presenten com a llegendes i els mites com a mites. Les versions, omissions i recreacions queden declarades; no es barregen variants ni s’afegeix una moralina. Les fonts institucionals o primàries s’han contrastat durant l’autoria i de nou en la revisió creuada. El text parlat aporta totes les dades de les preguntes. Els distractors proposen confusions del relat, amb una sola clau defensable. La gradació es confirmarà també amb l’àudio.
